# Wait, What?

The user did not follow your last message. Pitch it again:

- Open with one or two sentences of context: where the work stands and why
  this point came up.
- Then give the point itself in short sentences, one idea each: Simplified
  Technical English (ASD-STE100) when the user writes English, plain language
  (klarspråk) when the user writes Norwegian.
- Use the domain terms from the repository's glossary, such as `GLOSSARY.md`,
  the glossary `GLOSSARY-MAP.md` points to, or `CONTEXT.md`, and explain any
  technical term the user may not know.
- Keep it as short as the point allows, and end with the one thing you need
  from the user, if anything.
