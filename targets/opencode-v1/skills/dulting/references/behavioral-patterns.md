# Atferdsmønstre og sludge-audit

Bruk dette som en spørsmålsbank etter at brukerreisen og ønsket adferd er
avgrenset. Mønstrene er hypoteser, ikke dokumentasjon på effekt i den aktuelle
tjenesten.

## Diagnostiser barrieren

Fogg-modellen beskriver adferd som et samspill mellom motivasjon, evne og en
prompt. EAST undersøker om en handling kan bli enklere, mer attraktiv, mer
sosial eller mer tidsriktig. Bruk modellene til å finne spørsmål, ikke til å
erstatte brukerinnsikt.

| Observert barriere | Undersøk først | Typiske hypoteser |
|---|---|---|
| Brukeren kjenner ikke handlingen eller konsekvensen | Informasjonsbehov og språk | tydelig informasjon, konkret neste steg |
| Brukeren vil, men klarer ikke | Steg, dokumentkrav og tilgjengelighet | forenkling, forhåndsutfylling, stegvis avsløring |
| Brukeren vil og kan, men glemmer | Tidspunkt og kanal | kontekstuell prompt eller påminnelse |
| Brukeren kan, men ser liten verdi | Mål, tillit og dokumentert gevinst | relevant begrunnelse eller åpen personalisering |
| Brukeren har lav tillit | Årsak, avsender og databruk | åpenhet, forklaring og bedre kontroll |
| Tjenesten eller regelverket blokkerer | System- og prosesseier | strukturell endring, ikke dulting |

## Gjør sludge-audit først

Kartlegg hele reisen, også veien ut, angre, hjelp og alternative kanaler.

1. Tell steg, klikk, venting, bekreftelser, avbrudd og dokumentkrav.
2. Finn hvem som trenger hvert punkt og hvilket belegg som gjør det nødvendig.
3. Skill lov-, sikkerhets- og fagkrav fra historisk eller intern friksjon.
4. Se særlig etter asymmetri: lett å samtykke eller starte, men vanskelig å
   avslå, rette, avslutte eller få hjelp.
5. Fjern eller reduser unødvendig sludge før en sterkere intervensjon vurderes.

## Teknikkatalog

| Teknikk | Kan være relevant når | Viktigste guardrail |
|---|---|---|
| Forenkling | evnen er barrieren | ikke fjern nødvendig kontroll eller forklaring |
| Default | ett alternativ er dokumentert trygt for de fleste | forklar valget og gjør endring eller opt-out like enkelt |
| Fremdrift og små steg | oppgaven er lang eller uoversiktlig | ikke bruk fremdrift som skam eller press |
| Prompt eller påminnelse | brukeren vil og kan, men mister tidspunktet | begrens frekvens og respekter kanalvalg |
| Salience og handlingsspråk | neste steg blir oversett | behold presisjon om frivillighet og konsekvens |
| Sosial norm | sammenligningen er relevant og dokumentert | oppgi gyldig kilde, periode og populasjon; aldri dikt tall |
| Personalisering | dataene er forventede og forbedrer relevans | minimer data og unngå å avsløre sensitive forhold |
| Tapsframing eller tidspress | konsekvens og frist er sann og nødvendig | høyrisiko; krev faglig/juridisk avklaring i sårbare flyter |

## Dulting eller mørkt mønster

En ansvarlig dult bevarer reell valgfrihet, er forklarbar og gjør brukerens mål
lettere. Et mørkt mønster skjuler alternativer, skaper falsk knapphet, gjør
avslag vanskeligere, fabrikkerer belegg eller utnytter stress og sårbarhet.
Vurder hele reisen; en åpen tekst kan fortsatt inngå i en manipulerende flyt.

## Dokumenter evidensen

For hver valgt teknikk, noter hvilken observasjon som støtter barrieren, hvilken
mekanisme som forventes, hvilke grupper den kan virke annerledes for, og hva som
ville falsifisere hypotesen. Ikke generaliser en effekt fra en annen tjeneste
uten å teste overførbarheten.
